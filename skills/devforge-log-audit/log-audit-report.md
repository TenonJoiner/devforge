## 问题清单

> **格式铁律**：四个级别统一使用下方单条格式，每条独立成条、带编号前缀（C/H/M/L+序号）。**禁止**将同级别问题合并为一段归类描述，**禁止**某些级别用表格而另一些用段落——所有级别格式一致。

> "所属维度"取值：`级别合理性` 或 `打印频率`。

> "说明"：1-2 句，说清问题和影响即可。

> "修复建议"：具体可操作（降级为 X / 移出循环 / 加采样），不可只写"需要修复"。

> "预期收益"（CRITICAL 和 HIGH 必填）：1 句话量化整改效果，如"减少 X 条/秒""占比从 Y% 降至 Z%"。无 --log-dir 时标注"静态估算"。

## 自检清单

> 只检查审计报告的格式完整性，不检查具体审计判断。

- [ ] 审计元数据字段全部填写（未探测到的项已显式标注"未探测到/未提供"）
- [ ] 级别使用分析始终已填写；频率分析有 `--log-dir` 时已填写，无则已标注未审
- [ ] 四级问题格式统一：全部为编号前缀+独立条目，无表格/段落混用，无同级别合并描述
- [ ] 每条问题包含：编号前缀（C/H/M/L+序号）/ 标题 / 所属维度 / 说明（1-2 句）/ 修复建议（具体可操作）（缺一不可）

- [ ] 每条问题的"所属维度"为 `级别合理性` 或 `打印频率`
